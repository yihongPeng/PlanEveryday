# 芽芽计划 0.5.2 · 修复更新后的启动入口

- 修复升级完成后可能打开便携副本、导致“检查更新”按钮禁用的问题。
- 更新结束直接启动 D:/Programs/PlanEveryday 中刚安装的版本，并修复已有桌面和开始菜单入口。
- 已安装时，新的便携副本不会再将桌面入口或开机自启改到发布目录。
- 任务、记背、标签和图片继续使用 D:/PlanEverydayData；升级前自动备份。

0.5.1 如果已出现灰色检查按钮，请在设置正常退出，再运行 D:/Programs/PlanEveryday/PlanEveryday.exe，进入设置检查更新即可，无需搬运任何数据。0.4.1 及更早的便携版请手动运行本页安装包一次。

需要 Windows 10/11 x64 和可写 D 盘。测试范围和边界见仓库 docs/ACCEPTANCE.md。
