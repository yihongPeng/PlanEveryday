# 芽芽计划 0.5.1 · 一键更新与任务优先

这是首个公开的安装版。下载并运行 PlanEveryday-Setup-0.5.1.exe，即可接管桌面入口和现有 D 盘数据。0.4.1 及更早的便携版用户只需最后手动安装这一次，之后可以在设置 → 软件更新中下载、重启升级。

- 程序、数据、更新下载和解压缓存均放 D 盘，升级前自动备份，编辑草稿可恢复。
- 安装前完整校验，程序切换失败保留或恢复旧版；卸载默认保留个人数据。
- 任务标题更醒目，顶部与输入栏更紧凑，今日重点用浅苔绿突出。
- 点击桌宠、通知或提醒入口清除当前小点，保留记录，新提醒再次点亮。
- 更新检查/下载失败使用简短中文提示，不显示内部 HTTP 请求与错误堆栈。

需要 Windows 10/11 x64、可写 D 盘及足够安装空间。安装目录 D:/Programs/PlanEveryday，数据 D:/PlanEverydayData。安装包暂未购买商业代码签名证书。详细测试和限制见 docs/ACCEPTANCE.md。
