# 芽芽计划 0.4.0

- 记背支持粘贴截图、拖入图片、点击“插入图片”选择文件，图片离线保存在 D 盘。
- 备份 v4 包含任务、记背、标签与图片，兼容旧备份，校验后整体恢复；可通过完整备份修复本地缺失或损坏的图片。
- Markdown 代码块增加离线常用语言语法高亮。
- 调整桌宠点击的 Windows 前台授权及最小化还原聚焦，解决窗口仍停留在任务栏的问题。

使用：下载 ZIP 后完整解压，运行 PlanEveryday.exe。需要 Windows 10/11 x64 和可写的 D 盘，数据目录 D:/PlanEverydayData。升级前建议导出备份，退出旧版后运行新版。

图片：单张最多 10 MB、2500 万像素，转换为静态 PNG；已保存笔记引用图片总量最多 100 MB，完整备份最多 150 MB。请在插图后保存笔记；删除笔记暂不自动清理附件。外部图片链接不自动联网。

验证：34 项单元测试，打包版图片/备份 7 组、任务桌面 7 组、记背 6 组测试通过。真实剪贴板、资源管理器拖拽和鼠标点击桌宠的前台行为尚待人工复验，具体测试边界见 docs/ACCEPTANCE.md。
