# 芽芽计划 v0.3.1

Windows x64 便携版，本地离线个人计划助手，包含桌宠、提醒、Markdown 记背与标签筛选。

## 下载使用

1. 下载 `PlanEveryday-0.3.1-windows-x64.zip`，完整解压到 D 盘的固定文件夹。
2. 运行文件夹内 `PlanEveryday.exe`；程序会创建桌面快捷方式。
3. 点击桌宠打开计划。关闭窗口只是收起，在设置中选择退出才会结束后台程序。

**此版本需要可写的 D 盘**，正式数据、备份与缓存保存于 `D:\PlanEverydayData`。没有 D 盘时会报错停止，不回退 C 盘。不要仅复制 exe，运行需要保留整个解压目录。Windows 10/11 x64；使用系统 .NET Framework 桌宠组件。

## 本次更新

- 设置页增加“开机自启”，默认关闭，由用户选择开启或关闭。
- 开启后在登录 Windows 时启动，只显示桌宠与托盘，不主动弹出计划窗口；桌宠显隐沿用设置。
- 升级程序路径后更新已注册启动项；不擅自重新开启在 Windows 中禁用的项目。
- 开始使用 Git 管理源码，公开仓库采用 MIT 许可证。第三方组件许可证保留在发布目录。

## 验证与已知范围

29 项单元测试通过；发布包桌面、记背回归通过。实际 Windows 测试验证独立测试启动项的添加、移除与命令参数；模拟自启参数启动验证后台行为。未为测试重启整台电脑或注销用户。
