# 芽芽计划 0.5.0 · 一键更新与任务优先

安装包会自动创建/接管桌面入口，识别 D:/PlanEverydayData 中已有数据。旧便携版用户首次运行安装包即可，之后在设置的“软件更新”中检查、下载和重启更新。

- 任务、记背、标签和图片继续保存在 D 盘；更新前备份，格式迁移失败停止。
- 下载、解压和更新缓存放 D 盘；下载失败可重试，不自动退出安装。
- 更新前保存任务和记背编辑草稿，重新打开后恢复。
- 任务标题更突出，顶部与新增栏收紧，今日重点使用浅苔绿底。
- 点击桌宠、通知或提醒入口清除当前提醒小点；记录保留，新提醒再次点亮。

Windows 10/11 x64，需要可写的 D 盘。安装版位于 D:/Programs/PlanEveryday。便携版文件夹不会被自动删除；不要再从旧文件夹启动旧版。卸载默认保留个人数据。

当前安装包没有商业代码签名证书，更新文件通过 GitHub HTTPS 和 SHA-512 校验。具体已验证与未验证事项见 docs/ACCEPTANCE.md。
