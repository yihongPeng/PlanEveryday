# 记背正文目录

用户确认每篇正文的可点击目录。先交付本地验收版，验收通过后再 Git 提交、推送、发布和正式桌面更新。预览阶段保持 0.5.2 源码版本，不改写历史发布目录。2026-11-22 用户回复“同意改动”，随后以递增版本 0.5.3 正式交付。

2026-11-22 补充：用户要求每次修改代码均使用 `frontend-design`。本次选择精细、克制的阅读排版：目录从属于正文，用层级缩进、首层字重、轻底色和一致间距呈现，不增加标语、装饰纹理或持续动画。

## 交互

- 编辑页增加“生成标题目录”开关，默认关闭，随笔记保存；返回保留草稿。使用现有米白苔绿和克制排版。
- 阅读时按 Markdown 实际解析结果生成 h1–h6 标题目录，支持中文、行内格式、重复标题及 Setext 标题；代码块中的伪标题不计入。
- 目录位于正文之前，可折叠；长目录在自身区域滚动。展开状态在本次运行中保留。
- 点击目录在当前正文内滚动并聚焦标题，不启动浏览器、不改变窗口。标题应避开顶部粘性操作栏；工具栏提供回到目录的入口。
- 没有标题时给出一句添加 Markdown 标题的提示；标题变化后下次阅读自动更新。目录不写入/改写正文。

## 数据与实现

- 记背实体新增可选布尔字段 `toc`。旧条目没有字段视为关闭，无需覆盖或重写旧库；新条目默认 false。修改与保存继续通过已有事务。
- v1–v4 旧备份仍可读；包含 `toc` 的笔记自然参与现有快照/含图备份，不升级格式号。拒绝非布尔字段；恢复失败保留原库。旧版本校验允许附加记背字段，现有数据结构不因此不可读。
- Markdown 模块提供 `renderDocument(source) -> {html, headings}`，保留 `render(source)` 接口。使用同一 token 流生成正文锚点和目录，避免两种解析规则不一致。
- 锚点限于应用生成的前缀和安全字符；重复/空标题分配唯一标识，目录文本转义。内部锚点只在当前记背正文查找，外部 http(s) 链接继续走原受控接口。
- 不新增依赖，不修改提醒、安装器、自启或正式数据位置。

## 验收

自动测试：标题识别/层级、中文与重复锚点、空标题、恶意行内文本、代码和 HTML 安全；开关校验、事务失败、重启和旧/含图备份兼容。

桌面测试：独立 D 盘数据的打包应用，编辑开关保存、生成/关闭/折叠目录、点击与回到目录、长目录/长标题、360×480 与宽屏、更新正文后同步、隐藏释放后草稿和目录状态、退出重开、没有标题提示及外链分流。

验收版使用独立目录和虚构示例笔记，禁用正式入口/自启/更新，不覆盖用户日常版。自动化通过与用户验收通过分别记录；本次不声称安装更新链路重新验收。
