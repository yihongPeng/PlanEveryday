# 每日网格甘特图与导航图标重设计

2026-11-25：用户认为首版甘特图和底部图标不够美观，要求参考经典甘特图，每一天独立一个日期格，可拖动调整任务日期跨度。用户已认可重设计并授权落实，继续先交付隔离验收版，不操作屏幕、不提交或发布。用户已确认：跨多天的任务在跨度内每天显示于“今天”，完成后移出。

## 已识别的问题

现有时间轴日期标注过疏；阶段条较厚、单日任务标记与阶段含义不够直观；名称栏、留白和日期刻度比例失衡。底部导航使用不同 Unicode 字符，字形、粗细与视觉尺寸不统一。

## 方向选择

采用经典表格式甘特图，保留米白与苔绿。与“仅精修原有周刻度”相比，它能逐日对齐和抓取起止位置；与“卡片日历/看板”相比，它直接表达任务持续时间，更符合本次要求。先把表格、日期与时间条做好，不增加依赖箭头、资源分配、工时推算等功能。

## 视觉与布局

- 一体化网格，阶段和任务每行对齐。左侧固定名称，宽窗可显示天数；日期区横向滚动，表头固定。
- 表头两层：上方按月份合并，下方每一天显示“日期数字＋星期”。跨月不省略日期。默认每天约 44–52px，窄窗缩小名称栏并横滚时间轴，不把日期挤成细线。
- 周末使用很浅的背景；今天的表头浅绿、细竖线贯穿。网格中性细线，不做棋盘高对比，不让底色与任务抢注意力。
- 阶段用紧凑汇总行和细括号形范围条；普通任务用 24–26px 高、4px 小圆角的浅苔绿条，选中任务深苔绿。完成用勾选及浅色共同表达。未安排任务不伪造日期。
- 标题留在固定名称列，条内有空间时可显示简短标题，不反复堆叠日期文字。选中/悬停可读准确起止日，底部紧凑编辑区给出起止日期与天数。
- 主要区域留给图表。小窗表头仍逐日显示，任务名称可追踪；宽窗使用更多日期宽度。正式实现需按真实 360×480 窗口高度检查，不能用较高的设计预览代替验收。

## 任务跨度与拖动

- **任务本身也有起止日**，不再局限于阶段跨天、任务单日。普通单日任务是起止日相同的跨度，旧任务无需重新设置。
- 拖动条身：整体平移，持续天数不变。拖左端：调整开始日。拖右端：调整结束日。包含首尾当天，最短一天，不能拉成反向范围。
- 日期吸附到整天，移动达到阈值才开始拖动；拖动时显示起止日期和天数，Escape、捕获取消、隐藏取消未提交拖动；长时间轴拖到边缘时支持横向自动滚动。
- 普通任务释放后保存，给出简短反馈和撤销，避免每次调整都弹大对话框。保存失败恢复原条并保留候选日期供重试。键盘/日期输入可完成等价操作。
- 阶段整体移动沿用影响预览：默认仅改阶段；选择联动时整体平移未完成、已排期任务的两个端点，保持各任务跨度；提醒仍不跟随平移。批量变更显式确认，冲突需刷新预览再确认。
- 任务超出所属阶段范围允许保存并给出低干扰提示，可调整任务、扩展阶段或保留；不自动扩大阶段，也不自动移动其他任务。

## 与每日计划的结合（已获用户确认）

- 今天显示 start ≤ 今天 ≤ end 的未完成任务；同一任务只出现一次，不按天复制，不每天生成新记录。
- 完成一次即整体完成，从后续每日待办中移出。已完成仍可在项目/完成记录中查阅；这不是每日打卡或按天完成率。
- 结束日早于今天且未完成，才进入逾期区；开始日早于今天、结束日未到的任务仍属于进行中。
- 收集箱为两端均未安排的待办。七天安排按所选日期是否处于跨度中展示，同一天计数按不同任务 ID 计算。
- 今日重点是当天标记，每天仍所有项目合计最多 3 项；跨天任务的重点不能自动延续次日。改期后若仍包含重点归属日，可保留；不再包含时清除并反馈。与现有“focusDate 必须等于 plannedDate”的规则不同，实现时需完整升级校验与撤销逻辑。
- “安排到今天/明天”对已有跨度任务表示将开始日移到该日，并保持天数；明确提示范围。收集箱任务首次安排默认为一天。完整起止日期可在详情设置，避免快捷操作把多日任务压成一天。
- 提醒仍为一个明确时刻，不因跨度变更重复触发或自动改时间，确认/反馈可说明提醒不变。
- 保存、备份、旧数据迁移与旧版拒绝误开须覆盖新的任务结束日；不能只画长条而仍仅保存一天。新备份/数据库版本号在实现方案中确定，保留上一轮隔离试用内容。

## 底部导航

使用一套本地打包的线性图标，统一 24px 设计框、20–22px 显示尺寸、约 1.75px 笔画。图标与文字保留，不再混用字符图案或 emoji。

| 入口 | 图形含义 |
| --- | --- |
| 今天 | 带勾的日历 |
| 收集箱 | 收纳托盘 |
| 安排 | 日期网格 |
| 项目 | 三条错位的甘特时间条 |
| 记背 | 打开的书 |
| 更多 | 三点 |

未选中灰绿，选中深苔绿文字、图标后浅绿小底；取消铺满整个按钮的大色块与尺寸跳动。点击区域保持充分，宽窗侧边导航复用同套图标。实际应用离线可用，不从网络加载图标。

## 设计预览与下一步验收

对话预览位于忽略提交的 `test-results/designs/classic-daily-gantt.html`：虚构任务，可拖动条身和两端、日期输入、撤销、密度调整、导航图标选中状态。所有交互只作用于预览内数据，不操作应用或用户数据库。预览只含示例两周，不代表正式版只能调整两周范围。

无界面检查确认 14 个逐日日期格、条身平移/撤销、右端伸缩、左端键盘调整、日期表单、6 个图标、1024/460/360/320 宽度无页面横向溢出。只证明设计预览可用，不等于实际应用功能已实现。

用户已回复“可以可以，这一版看起来很不错呀”，授权按该设计实施；这属于设计认可，实际程序仍待亲自验收。实际验收重点：任务双端点可靠保存；日期格与横条逐像素对齐；单日、多日、跨月、跨年、拖出可见区域、失败与撤销；日期跨度内今日展示及完成一次；历史任务/备份与图片保留；小窗真实可操作面积；底部图标辨识度与点击区域。
