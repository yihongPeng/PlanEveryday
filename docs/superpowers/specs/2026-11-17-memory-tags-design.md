# 记背标签与温暖清爽视觉

用户选择米白＋苔绿、突出阅读。使用本机 frontend-design 技能整理视觉层级，保留离线与低占用约束。

## 行为
- 一篇可有 0–12 个标签，每个最多 24 个 Unicode 字符；编辑输入用中英文逗号或换行分隔，去除首尾空白、按大小写不敏感去重，保存第一次输入的显示写法。
- 复用已有标签，标签展示在列表与阅读标题下。点击标签只筛选，不进入编辑。
- 列表单标签筛选（全部、未分类、指定标签），与全文搜索取交集；显示结果数。返回列表和隐藏再打开保留筛选；清除筛选可回到全部。
- 旧条目补空标签，不改标题、正文、ID、创建/更新时间；schema v3 备份携带标签，继续支持 v1/v2。恢复备份后清空旧筛选草稿。

## 视觉
紧凑的记背页头、横向可滚动的标签栏、细线分隔的条目列表；每条提供标题、两行摘要、标签与更新时间。标签苔绿、阅读纸面米白、正文保持深灰；减少装饰与口号，不新增大图和网络字体。阅读页限制行宽，保留 Markdown 层级。编辑表单明确区分标题、标签、正文，已有标签可点击添加。

## 验收
标签添加/移除/去重/非法长度、旧库迁移、备份恢复、失败原子性、重启持久化；UI 保存后筛选、搜索交集、未分类、阅读返回、隐藏恢复草稿；360×480/900/1400 无页面横向溢出，Markdown 表格代码局部滚动；真实数据升级前后正文一致、桌面入口更新、D 盘路径不变。
