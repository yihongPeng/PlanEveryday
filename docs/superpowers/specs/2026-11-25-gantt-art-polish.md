# 甘特图美术细化

用户认可每日网格及现有排版，反馈 25 日贯穿图表的定位竖线不协调，整体美术仍需优化。本轮属于既定验收功能的视觉修订，不扩展项目功能，不操作屏幕或正式数据，仍待本人验收后提交发布。

采用“暖白纸面、清晰任务”的细化方向，保留既有米白＋苔绿。相比继续强化绿色区块或改成纯黑白，暖白与低饱和鼠尾草绿既延续现有配色，也让任务在网格前清晰可辨。

- 今天与目标日只在日期表头标记，取消贯穿任务行的实线和虚线。今天用小型深苔绿日期底，目标日用细框与文字；同一天时无重复色块，可访问名称包含两种含义。
- 日期网格改淡灰，周末用轻微中性色，阶段底略深于任务底。固定列、行高、日宽与滚动结构保持。
- 阶段括号减为 2px；其 27px 拖动命中区不缩小。任务条保留 25px 高度，改柔和绿色加细边界；选中深绿，完成项中性灰绿加勾，不依赖颜色表达状态。
- 中文字体优先微软雅黑 UI，宽窗名称 14px、条内文字 13px；不添加动画、纹理、装饰标语或图表周边模块。
- 选中任务悬停时保持深色底与白字，避免通用按钮悬停样式影响对比度。原有键盘焦点、拖动手柄、日期框和取消操作保留。

验收使用实际 UI 的合成任务截图与原有后台脚本：确认日期定位无竖线，日格与条宽对齐，平移/两端伸缩/取消/撤销/重试继续正常，小窗图表至少 120px且日期控件可达。视觉用独立验收包交付，保留旧预览试用内容；不以本次检查替代真实升级或系统缩放验收。
