# 项目与阶段甘特图实施计划

用户已批准设计与实现；使用 frontend-design 检查每部分布局，在“安静的温暖”方向内扩展。由用户亲自验收后才提交发布，本轮不操作屏幕。

1. 数据与兼容：项目、阶段、同一任务关联；阶段改期预览、事务与冲突安全撤销；完成/重开、归档/解除归属；数据库版本 2 与备份 v5，旧格式和图片兼容。隔离数据测试。
2. 项目工作区：列表、名称即可创建、详情、阶段和连续录入；任务优先，甘特切换；明确的阶段改期确认、可选平移、提醒不变；表单与会话保留。
3. 甘特视图：固定名称/日期、日周刻度、阶段范围/任务单日、未排期和范围外提示；拖动/尾部伸缩、Escape 取消，表单替代；内部横向滚动和小窗排版。
4. 现有视图联动：导航、任务项目/阶段编辑、批量归属、收集箱项目分组与七天安排筛选；今日重点上限、提醒和任务 ID 不变。
5. 验证：单元测试、真实本地页面加隔离 Store 的无界面测试；360×480、460×680 与宽屏、键盘、草稿/会话、拖动与撤销、备份恢复和迁移失败。
6. 交付：独立 D 盘验收数据与验收包，桌面只创建专用快捷方式，不启动；检查最终打包页面，记录证据和未测限制。正式安装、公开版本、Git 提交/发布保持不变。

模块接口约定：Store 提供 addProject/updateProject/deleteProject、addStage/updateStage/deleteStage、assignTasks、previewStageSchedule/applyStageSchedule/undoStageSchedule。界面调用同名 IPC action，参数使用对象；旧任务 add/update 保持兼容。ProjectView 与 ProjectGantt 独立模块，主 app 负责导航及共享任务编辑。
