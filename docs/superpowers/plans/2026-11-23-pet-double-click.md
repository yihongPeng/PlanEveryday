# 桌宠双击放大／还原

目标：按用户要求，双击桌宠切换计划窗口的最大化与原小窗；单击立即唤起同一个窗口，拖动不打开或切换大小。延续“安静的温暖”，仅扩充悬停操作说明。

实现决策：原生桌宠依据 Windows 双击时间和空间范围识别连续点击，第二次松开后才发送切换请求；拖动、右键和取消捕获会中断连击。第一次单击不等待双击计时。主进程统一处理窗口隐藏、最小化、渲染器已释放或仍加载的状态，准备完成前保留目标大小，避免加载后覆盖双击结果。无需新增常驻计时器或修改数据库。

替代方案：延迟单击可完全隔离单／双击，但会降低常用单击响应；直接依赖双击事件在第二次按下时切换，会把第二次按住拖动误判。采用完成后的连击判定。
