# 芽芽计划 Windows 首版实施计划

用户已授权按 AGENTS.md 的设计实现首版，并创建桌面入口。当前是空目录，无现有 Git 仓库或需隔离的改动。

**Goal:** 交付可启动的本地桌面应用、桌宠和桌面快捷方式。

**Architecture:** Electron 主进程管理窗口、托盘、通知和本地 SQLite；隔离的 preload 暴露受控 IPC。原生 HTML/CSS/JavaScript 渲染轻量响应式界面，不加载远程资源。

**Tech Stack:** Electron、Node 内建测试、SQLite、Playwright Electron 桌面测试。依赖通过 npm 锁定版本。

## 文件边界

- `src/store.cjs`：任务、设置、提醒、事务和备份。
- `tests/store.test.cjs`：先写行为测试，验证空标题、完成、重点上限、日期调整、提醒去重、恢复失败和数据持久化。
- `src/main.cjs`、`src/preload.cjs`：应用生命周期、受控 IPC、桌宠拖动、通知、托盘、窗口恢复。
- `src/ui/*`：计划界面、桌宠界面和视觉资源。
- `scripts/desktop-test.cjs`：真实 Electron 启动、任务闭环、窗口缩放与截图。
- `scripts/install-shortcut.ps1`：指向发布目录的桌面快捷方式。
- `docs/ACCEPTANCE.md`：记录已验证和未验证的验收条件。
