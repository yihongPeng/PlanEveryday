# 0.4.0 图片、代码高亮与桌宠唤起

用户已要求实现、测试并更新桌面与公开 GitHub。

设计：编辑正文支持粘贴图片、拖入文件、选择图片，在光标处插入本地 Markdown 引用。主进程校验并转换为 PNG，SHA-256 文件名去重，保存到 D:/PlanEverydayData/images。单图输入及转换结果最多 10 MB、2500 万像素。外部图片仍不自动联网。读取仅允许严格的内容哈希地址，禁止任意磁盘路径。

备份 v4 使用单个 JSON，包含被保存笔记引用的图片（base64、哈希校验），合计图片最多 100 MB，文件最多 150 MB。兼容旧 v1–v3；先完整校验、备份当前内容、写入不可变附件，最后事务恢复数据库。失败保留旧数据；不清理历史图片，避免误删草稿引用。

代码高亮采用本地 highlight.js 常用语言，未知语言回退纯文本，HTML 始终转义。温暖浅色主题，长代码只在代码块内滚动。

桌宠点击在原生进程接收，向父进程明确授予 Windows 前台权限；主窗口还原并聚焦，保持非置顶。验证原生点击与主窗口最小化路径。

实施与验收：
- 附件校验、去重、缺失/损坏拒绝、恢复失败保留数据的单元测试。
- Markdown 本地图片、高亮、恶意链接与外部图片测试。
- 打包 Electron 中粘贴、拖入、选择、取消、大小限制、草稿、重启、备份到干净目录恢复、小窗排版测试。
- 桌宠真实 Windows 点击最小化/后台/隐藏窗口；不把模拟回调视作鼠标实测。
- 回归原有数据和桌面测试；真实数据备份后更新快捷方式与 GitHub Release。
